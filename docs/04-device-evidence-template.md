## 3. M5.4 device flow script

Per device, in order:

1. Fresh install → onboarding (paste key, management toggle) → Home populated.
2. Spend tab: management key → standard key → airplane mode (stale badge).
3. Providers catalog: search, sort, status links.
4. Policy: toggle one provider, reopen the tab, confirm read-back on the dashboard.
5. Keys: create → reveal → copy → test → collapse → revoke.
6. Clear stored key → restart → onboarding shown again.

Record any deviation and whether it reproduced on the second device.
